RAILWAY SETUP

1. Upload this project or connect its GitHub repository.
2. In Railway open Variables.
3. Add:
   BOT_TOKEN = your Telegram BotFather token
4. Optional:
   HISTORY_URL = https://draw.ar-lottery01.com/api/WingO/WingO_1M/GetHistoryIssuePage.json
5. Deploy/redeploy.

Commands:
 /start
 /stats
 /stats 50

The bot calculates historical colour frequencies only. It does not guarantee future lottery results.
